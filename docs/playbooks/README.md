# Playbooks

Wie wir die drei Dinge betreiben, an denen Outbound am häufigsten scheitert. Jede Regel mit Warum. Die Agenten lesen diese Dateien, du kannst sie auch ohne Agenten nutzen.

| Datei | Worum es geht | Owner-Agent |
|---|---|---|
| [`zustellbarkeit.md`](zustellbarkeit.md) | Mails kommen im Posteingang an, nicht im Spam | outbound-zustellung |
| [`kennzahlen.md`](kennzahlen.md) | Eine Kennzahl, die entscheidet: Mails je positiver Antwort | outbound-kaltakquise, master |
| [`zielgruppe-aus-positiven.md`](zielgruppe-aus-positiven.md) | Zielgruppe aus echten Antworten ableiten statt raten | outbound-zielgruppe |
