# Beispiele: Eingabe → Ergebnis

> **Alles in diesem Ordner ist erfunden.** Firma, Personen, Zahlen und Ergebnisse sind ein Beispiel, damit du siehst, wie ein fertiges Ergebnis aussieht. Kein Agent übernimmt Werte von hier. Deine echten Werte stehen in `firma/`.

## Die fiktive Firma

**Werkplan GmbH (fiktiv).** Verkauft eine Software für Wartungsplanung an Maschinenbauer mit 50 bis 250 Mitarbeitenden in Deutschland. Käufer: Geschäftsführung und Leitung Instandhaltung. Lead Magnet: eine Checkliste "Die 12 Wartungsfehler, die Stillstand kosten", angepasst auf den Maschinenpark des Empfängers.

## So nutzt du sie
- **Als Maßstab.** Liefert ein Agent etwas deutlich Längeres oder Unschärferes, zeig ihm das Beispiel und sag "so".
- **Als Prüfliste.** Der Prüfer (`kontrolle-review`) vergleicht neue Ergebnisse mit dem Aufbau hier.
